# Diffinity

A modern text comparison tool for macOS built with SwiftUI.

## Features

- Real-time text comparison
- Character-level diff highlighting
- Line numbers
- Dark/Light mode support
- Statistics for changes (additions, removals, total lines)
- Modern macOS native UI

## Requirements

- macOS 12.0 or later
- Xcode 14.0 or later

## Installation

1. Clone the repository
```bash
git clone https://github.com/yourusername/Diffinity.git
```

2. Open the project in Xcode
```bash
cd Diffinity
open Diffinity.xcodeproj
```

3. Build and run the project (⌘R)

## Usage

1. Enter or paste text in either panel
2. Click "Check Differences" button or use ⌘R shortcut
3. View the differences highlighted in:
   - Red for removed content
   - Green for added content
4. Toggle dark/light mode with ⌘⇧D
