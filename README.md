## ✨ Key Features

- 🔍 **Real-time Text Comparison**: Instantly compare two text inputs
- 🎨 **Character-level Diff Highlighting**: Precise visualization of differences
- 📊 **Line Numbers**: Easy reference for text positions
- 🌓 **Dark/Light Mode**: Seamless theme switching
- 📈 **Change Statistics**: Track additions, removals, and total lines
- 💻 **Native macOS UI**: Optimized for Apple's ecosystem

## 🚀 Quick Start

1. Clone the repository:
```bash
git clone https://github.com/yourusername/Diffinity.git
cd Diffinity
```

2. Open the project in Xcode:
```bash
open Diffinity.xcodeproj
```

3. Build and run the project (⌘R)

## 💻 Usage Guide

1. **Text Input**
   - Enter or paste text in either panel
   - Support for large text files

2. **Comparison**
   - Click "Check Differences" button
   - Use ⌘R shortcut for quick comparison
   - View differences highlighted in:
     - Red for removed content
     - Green for added content

3. **Interface**
   - Toggle dark/light mode with ⌘⇧D
   - View statistics panel for change metrics
   - Use line numbers for easy reference

## 🔒 Privacy & Security

Diffinity processes all text locally on your machine. No data is sent to external servers, ensuring complete privacy for your content.
